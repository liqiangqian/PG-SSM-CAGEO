# Aggregate manuscript evidence

This directory contains transcription-level aggregate evidence from the final submission documents. The CSV files reproduce table-level counts and summary metrics only; they are not outputs recomputed from the public synthetic demonstration.

`synthetic_results.json` is separate executable evidence. It verifies the public code path, dimensions, causal preprocessing, and CPU workflow, but it does not reproduce confidential field-derived numerical results.

No file in this directory contains raw industrial records, actual identifiers, actual coordinates, row-level observations or predictions, or the protected frozen field-result bundle.
