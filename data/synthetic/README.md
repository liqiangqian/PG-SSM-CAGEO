# Synthetic Demonstration Dataset

This directory contains synthetic demonstration data for the public PG-SSM workflow.

Files:

- `synthetic_five_spot.csv`: synthetic long-format five-well monitoring table.
- `synthetic_units.csv`: synthetic unit-level metadata.

This dataset is synthetic and is provided only for workflow verification. It must not be interpreted as field data.

The data use anonymized unit identifiers such as `U_SYN_001`, anonymized well identifiers such as `W0` to `W4`, and synthetic local coordinates. They do not contain real mine names, real well names, real coordinates, real injection or extraction records, real reagent information, or real uranium concentration sequences.

The synthetic dataset has a similar general variable structure to the manuscript workflow, but it cannot reproduce the confidential site-specific numerical values or the exact performance metrics reported in the manuscript.
